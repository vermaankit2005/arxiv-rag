Eval Benchmarks

Every evaluation this system is graded on, grouped by the component it tests. Each one carries a benchmark — the score that counts as healthy — next to the score it actually gets, so the gap is the point rather than a footnote. Scores come from LangSmith experiment runs.

How each benchmark was set

  • Proven reachable. Where a run has already hit a level, that level becomes the bar — citation support scored 0.932 once, so 0.90 is not aspirational.
  • Capped by the metric. Two retrieval metrics cannot reach 1.0 by construction. Their benchmarks sit near the real ceiling, and the unreachable range is drawn in grey on every gauge.
  • Anchored to the rubric. Where a judge scores against a written rubric, the benchmark is the rubric level being asked for — naturalness 0.75 is the judge's own definition of "natural overall".
  • Zero tolerance where a failure ships. Safety leaks and broken citation anchors get 1.00, because one failure is one too many.
